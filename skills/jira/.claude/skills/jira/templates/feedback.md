# Feedback template

Issue type: `Feedback`. Use for feature requests and suggestions. Modeled on WT-3677.

## Summary

- `<Product> Suggestion: <short imperative description>`
- Example: `Planning Suggestion: Streamline adding multiple songs`

## Description

```markdown
<One or two sentences summarizing the request and the problem behind it.>

---

> <Customer quote, with identifying details removed>
>
> \> <source link>

> <Another customer quote, if several sources ask for the same thing>
>
> \> <source link>
```

Notes:

- Quote the customer's own words for the request. Trim greetings, sign-offs and unrelated content. Replace identifying details with a bracketed placeholder such as `[church name]`.
- One blockquote per source, each followed by its link.
- Subsequent / Duplicate feedback should be appended to the list of quotes if the issue is open; otherwise it should be appended as a comment.
