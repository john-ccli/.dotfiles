# Task template

Issue type: `Task`. Use only when the user says this is work we will do. Never infer it from a customer report.

## Summary

- Make it action-oriented, e.g., `Implement feature X`
- Example: `Show a success toast after accepting an account invitation`

## Description

- Example:

```markdown
<What needs to be done and why, in a few sentences. Use GIVEN/WHEN/THEN from the bug template when the task is about behavior.>

---

- <Relevant code: `functionName` in `web/src/path/file.ts`>
- <Suggested approach>
- <Other important context, related tickets>
- Reported in: <source link(s), if any>
```
